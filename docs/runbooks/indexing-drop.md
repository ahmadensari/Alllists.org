# Indexing drop

**Who:** the engineer and the founder. **Needed:** submitted versus indexed pages falls, or less than 20% are indexed at day 90.

1. Search Console: look for manual actions, crawl errors, and "crawled, not indexed" counts.
2. Check `robots.txt` and a list page's `robots` meta: pages are indexed only when a country's index switch is on and the list has at least 10 checked entries. Filter pages are never indexed.
3. Check that sitemap shards respond and list only indexable pages, and that canonical links point to the clean address.
4. Check page speed and server errors in the log for the same dates.
5. If the pages are thin, the fix is more checked data, not more pages. Do not add doorway pages.
