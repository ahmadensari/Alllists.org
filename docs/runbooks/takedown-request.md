# Takedown and erasure request

**Who:** the moderator on duty. **Deadline:** 30 days from the request (the queue shows the due date, sorted soonest first). **Needed:** a row in `/staff/takedowns/`, created when someone uses "Remove my data" on an entry.

1. Open `/staff/takedowns/`. Confirm who is asking. For a person, ask them to prove they hold the phone number or email on the entry (a one-time code sent through the platform).
2. If the request is legitimate, choose **Erase**. The entry becomes a tombstone: name and personal fields are replaced, contacts and social links are deleted, and the contact hashes and the name go on the global do-not-contact list so a re-import cannot bring it back.
3. If it is not legitimate (for example a competitor asking to remove a rival), choose **Refuse** and write the reason. The reason is stored.
4. For a subject-access request use `/staff/subject-access/`, then send the downloaded file to the requester by email.
5. For a person who consented and now withdraws: `/staff/consent/` then **Record withdrawal and take down**.
6. Check the entry page returns "not found" or the tombstone, and that a search for the name finds nothing.
